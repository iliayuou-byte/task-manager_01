# Общие дела в ChatGPT и Telegram

Этот бот хранит дела в `iliayuou-byte/task-manager-data`, файл `task-table.md`, ветка `main` (фактический путь задаётся `FILE_PATH`). В рабочем чате с подключённым GitHub можно читать и менять тот же файл. Отдельный MCP-сервер для этого варианта не нужен: инструменты уже предоставляет подключение GitHub. Доступ к чтению и записи этого репозитория проверен; пробная запись в реальные задачи не выполнялась.

Примеры просьб в ChatGPT:

- «Посмотри актуальные дела моего Telegram-бота и помоги выбрать три на завтра».
- «Перенеси дело про CV в важно и срочно, защитив мой выбор».
- «Добавь в общий список позвонить в банк завтра».

Если начинаете новый чат, укажите репозиторий и путь файла; там должно быть доступно подключение GitHub с разрешением на этот репозиторий. Перед каждым изменением помощник должен читать свежую версию и использовать её blob SHA при обновлении файла. При конфликте SHA нужно перечитать файл и проверить изменение заново. Нужно сохранять остальные строки, frontmatter, ручные категории, завершённые дела и все столбцы. Номера из старого экрана Telegram не являются постоянными ID: для изменений из ChatGPT используйте название и свежий список. Изменения станут видны в Telegram при следующем открытии списка; чтение списка не отправляет сообщение в Telegram.

## «Поговорить» в Telegram

После обновления и перезапуска появится шестая кнопка главного меню **💬 Поговорить**, также доступна `/talk`. Нижняя клавиатура главного меню занимает три ряда по две кнопки; «Назад»/«Меню» появляются внутри разделов.

В этом режиме можно писать или отправлять ГС:

- «Я устал, но хочу немного продвинуть дела. С чего начать?»
- «CV важнее сопромата сегодня? Помоги разобраться».
- «Добавь завтра позвонить в банк».
- «Удали дело про покупку хлеба».

Помощник видит до 80 текущих задач и последние 20 завершённых из хранилища. Для разговора хранит последние шесть пар реплик отдельно для каждого пользователя и личного чата. Память переживает перезапуск и перестаёт использоваться через семь дней без новых реплик. Файл `runtime/assistant-history.json` исключён из Git; истёкшие записи удаляются при следующей записи в историю. Полная история аккаунта ChatGPT не передаётся. Для переноса сервера история переносится отдельно, если нужна.

Ответы краткие, разговорные, с уважением к усталости и ручным приоритетам. Бот может задавать уточняющие вопросы; нельзя обещать, что ИИ всегда верно оценит важность. Обычный разговор задач не меняет. При явной просьбе добавить или удалить появляются предложение и кнопка **📝 Подготовить черновик**. Она запускает существующий предпросмотр, после которого нужно отдельно подтвердить сохранение или удаление.

**🧹 Забыть разговор** удаляет историю этого личного чата, но сохраняет задачи. **Назад/Меню** закрывает режим, сохраняя историю; ответ ожидающего запроса после закрытия не показывается. Через 30 минут без использования режим нужно открыть снова. Разговоры используют OpenAI API; голос сначала расшифровывается локально при включённом Whisper.

## Изменить характер бота

В `.env` можно добавить одну строку:

```dotenv
ASSISTANT_STYLE=Отвечай коротко и по-дружески. Допускай лёгкий юмор. Если я перегружен, предлагай один небольшой шаг. Избегай пафоса и нравоучений.
```

Сохраните файл и перезапустите бот. Основная инструкция и формат ответа находятся в `src/clients/ai.ts`, функция `generateAssistantReply`; тексты экрана и переходы — в `src/commands/assistant.ts`. Изменять инструкции можно, сохраняя правило: ИИ предлагает, пользователь подтверждает. Этот режим не отправляет инициативных сообщений вне текущего разговора; напоминания настраиваются отдельно в меню.
