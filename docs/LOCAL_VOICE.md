# Локальные голосовые и OpenAI

Голос расшифровывает faster-whisper на компьютере, где запущен бот. Полученный текст отправляется в OpenAI для разбора дел. Для OpenAI нужен отдельный API-ключ и оплата API; подписка ChatGPT не оплачивает эти запросы. Ключ хранится только в `.env`.

## Mac

Остановите бот через Ctrl+C. В папке проекта выполните:

```sh
git pull origin feature/daily-copilot-now
bun install
python3.12 --version
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements-voice.txt
.venv/bin/python scripts/transcribeVoice.py --prepare
```

Используйте Python 3.12. Установщик для Mac: https://www.python.org/downloads/release/python-31210/ (macOS 64-bit universal2 installer). На Intel Mac окружение Python 3.14 может не находить пакет onnxruntime. Если `.venv` уже создана другой версией Python, пересоздайте только окружение командой `python3.12 -m venv --clear .venv`; `.env` сохраняется. Установка библиотек зависит от доступности пакетов для вашей версии Python и архитектуры Mac. При ошибке установки сохраните текст ошибки без секретов.

Первый запуск `--prepare` скачивает модель `small` и может занять несколько минут. Нужен интернет. Отдельно устанавливать FFmpeg для этого обработчика не требуется.

Если распознавание выдаёт `TypeError: open() got an unexpected keyword argument 'metadata_errors'`, установлен несовместимый PyAV 19. Обновите ветку и снова выполните `.venv/bin/python -m pip install -r requirements-voice.txt`: зависимости ограничивают PyAV версией ниже 19. Проверка `--prepare` только загружает модель и не проверяет декодирование настоящего аудио.

## Windows 11

После установки Python 3.12 в PowerShell из папки проекта:

```powershell
git pull origin feature/daily-copilot-now
bun install
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-voice.txt
.\.venv\Scripts\python.exe scripts/transcribeVoice.py --prepare
```

Активация виртуального окружения не нужна. Перенесите `.env` безопасным способом на ноутбук. Запускайте только один экземпляр polling-бота с этим Telegram-токеном: перед запуском на Windows остановите его на Mac.

## Настройка `.env`

Создайте ключ на https://platform.openai.com/api-keys и настройте оплату API в кабинете OpenAI. Измените следующие строки в существующем `.env`, сохранив настройки Telegram и GitHub:

```dotenv
AI_PROVIDER=openai
AI_MODEL=gpt-4.1-mini
OPENAI_API_KEY=ваш_ключ
OPENAI_BASE_URL=
VOICE_TRANSCRIPTION_PROVIDER=local
WHISPER_PYTHON=
WHISPER_MODEL=small
WHISPER_LANGUAGE=
```

Пустой `WHISPER_PYTHON` автоматически выбирает Python из `.venv`. Если окружение находится в другом месте, укажите полный путь к его Python. Пустой `WHISPER_LANGUAGE` включает определение языка; `ru` фиксирует русский язык.

Запуск:

```sh
bun run start:polling
```

Проверьте сначала короткое голосовое с одним делом, затем список. Бот должен показать черновик, который нужно подтвердить перед сохранением.

## Скорость и повторы

- Расшифровка работает на CPU с int8. Скорость зависит от ноутбука; ограничение ожидания — четыре минуты. Принимаются ГС до трёх минут и 8 МиБ.
- Если `small` работает медленно, смените `WHISPER_MODEL=base`. Модель будет загружена при первом голосовом. Более лёгкая модель может хуже распознавать речь.
- Если текст распознан, но разбор ИИ не удался, он сохраняется в `runtime/pending-inputs.json` на 24 часа. Исходное ГС остаётся при ошибке. После истечения срока текст удаляется при следующем чтении очереди.
- В Терминале ошибка разбора отмечается `[INPUT_RETRY] status=... kind=...`: `authentication` — авторизация, `missing_key` — ключ отсутствует, `billing` — оплата/лимиты, `model` — модель, `schema` — формат ответа, `temporary` — временный сбой. Диагностика не выводит ключи, текст дел или сырые ответы провайдера.
- При временном лимите или перегрузке polling-бот делает максимум два отложенных повтора. Ошибки оплаты и авторизации автоматически не повторяются.
- «Назад»/выход в главное меню останавливает отложенные повторы. Кнопка «Повторить разбор» или `/retry` запускает сохранённый текст снова, без новой расшифровки.
- Повтор создаёт только черновик добавления или удаления. Изменения задач требуют подтверждения.
- Очередь и `.venv` исключены из Git. Не публикуйте `.env` или содержимое очереди.

Эта схема рассчитана на постоянно включённый компьютер и `start:polling`. На Vercel локальный Python-процесс и фоновая очередь этой схемы не поддерживаются. Сон или выключение ноутбука приостанавливают обработку.

Сбой самого Whisper сохраняет исходное ГС, но не ставит аудио в фоновую очередь: повторите его после исправления установки. Локальная расшифровка не расходует OpenAI API; разбор текста расходует API и также имеет лимиты.
