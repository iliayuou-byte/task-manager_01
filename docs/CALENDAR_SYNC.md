# Расписание в Google Calendar и приложении «Календарь» Apple

Бот хранит импортированное расписание `.ics` в своём файле задач. После загрузки
файла он также переносит занятия в календарь, указанный в
`GOOGLE_CALENDAR_ID`. На iPhone и Mac добавьте тот же Google-аккаунт в
приложение «Календарь»: события будут видны в обоих приложениях, но останутся
одной копией в Google. Синхронизация с отдельным календарём iCloud здесь не
настраивается.

## Подключение

1. В Google Calendar создайте отдельный календарь для расписания, например
   «Учёба». Скопируйте его **идентификатор календаря** из настроек в
   `GOOGLE_CALENDAR_ID` вашего `.env` на устройстве, где работает бот.
2. В Google Cloud включите Google Calendar API и создайте сервисный аккаунт.
   Скачайте его JSON-ключ в файл, указанный в
   `GOOGLE_CALENDAR_CREDENTIALS_PATH`. Не добавляйте ключ в репозиторий.
3. Поделитесь календарём «Учёба» с `client_email` из JSON-ключа и дайте право
   изменять события. Перезапустите бота.
4. На iPhone: «Настройки» → «Приложения» → «Календарь» → «Учётные записи» →
   «Добавить учётную запись» → Google; включите календари. На Mac добавьте тот
   же Google-аккаунт в «Календарь».

Если бот работает с `NODE_ENV=production`, он использует вместо JSON-файла
`GOOGLE_CALENDAR_PRIVATE_KEY`, `GOOGLE_CALENDAR_CLIENT_EMAIL` и
`GOOGLE_CALENDAR_PROJECT_ID` из переменных окружения.

## Повторный импорт

Отправьте `.ics` прямо в личный чат бота или через «📅 Календарь» →
«📤 Импортировать .ics». После проверки файла бот сразу сохранит расписание и
начнёт синхронизацию. При повторной загрузке он обновляет найденные занятия,
добавляет новые и удаляет только
события, которые сам создал при предыдущем импорте. Личные события не
затрагиваются. Если сервис недоступен, расписание останется в боте. После
исправления подключения нажмите «🔄 В Google Calendar», чтобы повторить
синхронизацию без повторной загрузки файла.

Текст `.ics`, вставленный сообщением вместо файла, по-прежнему требует
подтверждения предпросмотра. Для нескольких пользователей внешняя
синхронизация доступна только владельцу бота.
