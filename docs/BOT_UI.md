# Как менять тексты и оформление бота

Открывай проект `task-manager_01` в VS Code на Mac. Для поиска по всем файлам: `Cmd+Shift+F`, затем фраза из сообщения или подпись кнопки.

| Что изменить | Файл |
| --- | --- |
| Названия кнопок главного меню | `src/views/menuView.ts`, объект `MENU` |
| Приветствие, карточка дела, тексты настроек | `src/commands/menu.ts` |
| Экран разговора, очистка памяти, предложение черновика | `src/commands/assistant.ts` |
| Характер разговорного ИИ | `.env`: `ASSISTANT_STYLE`; `src/clients/ai.ts`: `generateAssistantReply` |
| Заголовки четырёх разделов | `src/services/eisenhower.ts`, массив `QUADRANTS` |
| Строки списка дел, даты, теги, разделители | `src/views/eisenhowerView.ts` |
| Предпросмотр нового списка и вопросы о категории | `src/commands/brain.ts` |
| Подтверждение удаления | `src/commands/removeSelected.ts` |
| Список разрешённых тегов и инструкция ИИ | `src/services/taskTags.ts` |
| Компактная раскладка и страницы кнопок | `src/services/contextKeyboard.ts` |
| Очистка старых экранов | `src/services/chatPanel.ts` |

## Текст сообщения

Вызовы `panelReply(ctx, 'текст')` создают экран и убирают предыдущий экран после успешной отправки. Перенос строки внутри строкового литерала: `\n`. Не удаляй `panelReply` и не заменяй его обычным `ctx.reply`, если хочешь сохранить очистку чата.

Для простого форматирования нового сообщения можно использовать HTML:

```ts
await panelReply(ctx, '<b>Мои дела</b>\nВыбери следующее действие.', {
  parse_mode: 'HTML',
});
```

`<b>` — жирный текст, `<i>` — курсив, `<code>` — моноширинный текст. Это Telegram-форматирование, не полноценная веб-страница: CSS и собственный шрифт не задаются. В динамических названиях при HTML-режиме нужно экранировать `&`, `<`, `>`, иначе пользовательский текст может сломать сообщение. Сообщения с `MarkdownV2` используют другое экранирование: не меняй только `parse_mode`, оставляя прежнюю разметку.

## Кнопки

```ts
new InlineKeyboard()
  .text('Моя подпись', 'menu:settings')
  .row()
  .text('⬅️ Назад', 'menu:home');
```

Первый аргумент `.text()` — видимая подпись. Второй — действие. Для смены названия меняй только первый аргумент. Для нового действия нужен обработчик, одной подписи недостаточно. Обычные callback-кнопки автоматически превращаются в нижнее контекстное меню: до шести действий на странице, по две кнопки в ряд, навигация отдельной строкой. Длинные подписи сокращаются; полное название дела остаётся в сообщении. Две кнопки с одинаковой сокращённой подписью и разными действиями получают номера, чтобы не перепутать выбор.

Telegram определяет физическую высоту и ширину кнопок на устройстве. Проверь результат на телефоне: локальное окно VS Code не показывает настоящий интерфейс Telegram.

## Защита категории

«Защитить категорию» сохраняет `priorityLocked`. ИИ не переносит это дело между разделами при автоматической переклассификации. Ручное изменение всегда доступно. «Разрешить ИИ менять раздел» снимает защиту. Это не закрепление сообщения в чате.

## Теги

Теги описывают область дела; важность и срочность задаются отдельно. ИИ предлагает теги в том же запросе, которым разбирает задачу. Дополнительный запрос к модели не нужен. Предложение проверяется по словарю; семантическая точность не гарантируется. Если область неясна, допускается пустой список. Явные пользовательские хештеги поддерживаются.

| Тег | Примеры |
| --- | --- |
| `#учёба` | Экзамен, библиотека, подготовка к занятиям |
| `#работа` | Задачи работодателя, клиенты, рабочая 1С |
| `#дом` | Мусор, уборка, одежда, установка телевизора |
| `#здоровье` | Тренировка, врач, сон |
| `#покупки` | Продукты, техника |
| `#документы` | Посылки, возвраты, заявления |
| `#финансы` | Оплата счетов, бюджет |
| `#проекты` | Личный бот, Kür, собственные разработки |
| `#личное` | Встречи и личные планы |

Чтобы исправить тег уже сохранённого дела, открой карточку → «Изменить» → «Tags» и введи, например, `#дом`. Добавление словаря не меняет старые задачи автоматически.

## Проверка и запуск

```bash
bun run build
bun run lint
```

После успешной проверки останови текущий процесс через `Ctrl+C` и запусти `bun run start:polling`. Пока бот работает на Mac, тестируй изменения там; после переноса на Windows рабочий экземпляр должен оставаться один. `.env` в GitHub не отправляй.

В предпросмотре распознанных дел «🗑 Удалить дело» открывает выбор ошибочного
задания. В последовательном разборе кнопка «🗑 Удалить» убирает текущее дело и
переходит к следующему. Удаление затрагивает только черновик, сохраняет номера
остальных дел и не вызывает ИИ повторно. В хранилище попадут только оставшиеся
дела после «✅ Сохранить». Пустой черновик отменяется.
