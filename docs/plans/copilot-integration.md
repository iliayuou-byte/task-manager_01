# Совмещение личной системы с текущим Copilot

Пользователь запускает Windows-копию ветки `feature/daily-copilot-now` на коммите
`58f958a`. Она содержит голосовые, помощника, меню, отдельные профили,
импорт расписания, утренние чек-листы и управление Fire TV. Личная система из
`feat/personal-planning` должна дополнять эту версию и сохранять её настройки.

## Решения

- session-settled: сохранить существующие сценарии текста, голосовых и `/talk`.
  Входящие без ИИ добавляются явно через `/inbox текст`.
- session-settled: `/reminders` остаётся прежней командой; новые расписания
  управляются `/personalreminders` и могут работать независимо.
- Владелец определяется через `profileOwner()`. Новые личные команды доступны
  только ему в личном чате, фоновые проверки выполняются в его профиле.
- Столбцы задач читаются по заголовкам: обе ветки добавили поля после старых
  двенадцати столбцов. ID и признаки важности/срочности должны переживать запись.
- Успешное сохранение обновляет ревизию исходного снимка значением из ответа
  GitHub. Устаревший снимок отклоняется, а не перезаписывает свежие задачи.
- Расписание `.ics` участвует в плане и напоминаниях, без копирования в задачи
  и статистику завершений. Часовой пояс календаря преобразуется в пояс владельца.
- Единственная точка polling — `src/polling.ts`. Она запускает оба планировщика
  и повторные попытки обработки ввода. Активный webhook отключается явно через
  `clear:webhook`, с сохранением ожидающих обновлений.
- Прогресс расшифровки голосового не может переиспользоваться для нового меню:
  завершение старой операции должно удалять только её сообщение состояния.
- Секреты остаются в локальном `.env`; личные данные — в приватном репозитории.
  Экспорт для коучинга остаётся агрегированным, по согласию и явному запросу.

Проверки выполняются с поддельными транспортами Telegram/GitHub/ИИ, без доступа
к пользовательским задачам и токенам. На исходном `58f958a` отдельно воспроизведены
14 неудачных тестов интерфейса/голосовых и ошибка TypeScript в Fire TV.
Исправления сохраняют предметные проверки и добавляют проверку гонки очистки
голосового статуса. Локальные проверки не заменяют реальный запуск на Windows.
