# Личная система: план реализации

## Цель

Дополнить существующий однопользовательский бот: быстро фиксировать дела,
выбирать до трёх результатов дня и возвращаться к выполнимому плану после
срыва расписания. Сохранять действующие команды и Google Calendar.

## Оценка исходного кода

- TypeScript, Bun, grammY, Hono; исходная точка `de92c9c`.
- Задачи хранятся в Markdown на GitHub или в Notion. В этом расширении
  используется GitHub; личное состояние допускается только в приватном репозитории.
- Google Calendar уже подключён, добавление события подтверждается кнопкой.
- Сессии в памяти подходят для коротких диалогов, но не для дневника/согласия.
- До проверки allowlist подключены сцены; проверку необходимо перенести вперёд.
- Cron отправляет один список по UTC, локального планировщика для Windows нет.
- При чтении Markdown теряется `log`, поэтому история завершения ненадёжна.
- Есть 10 тестов Notion/фабрики, тестов сценариев Telegram пока нет.

## Последовательность

### Основа и данные

1. Проверять allowlist до сцен. Личные команды — только первому пользователю
   allowlist и только в личном чате.
2. Добавить необязательные ID задач и время завершения в конец Markdown-таблицы;
   старые таблицы читаются без ручного переноса. Сохранить `log`.
3. Хранить настройки, дневные планы, обзоры, цели и согласие в отдельном
   `personal-system.json` рядом с таблицей задач в том же приватном репозитории.
   Проверять схему и владельца. Обновлять с SHA, при конфликте перечитывать
   состояние и повторять изменение; не перезаписывать чужие изменения.

### Ежедневная работа

4. `/inbox текст` сохраняет задачу без ИИ и срока; `/inbox` показывает входящие.
5. `/focus` предлагает выбор до трёх задач кнопками; `/morning` показывает
   выбранные приоритеты, события, первый шаг. Учёба/зал/проекты/общение — теги.
6. `/late` оставляет один ближайший шаг и будущие события, `/lowenergy` — один
   шаг на 5 минут, `/normal` возвращает обычный вид. Дела не удаляются и
   автоматически не переносятся.
7. `/evening` предлагает короткий обзор; форма сохраняет энергию, результат,
   препятствие и следующий шаг. Незавершённое не становится автоматическим долгом.
8. `/week` считает завершения по времени фактического завершения, обзоры,
   режимы дня и активность по направлениям; неизвестные старые даты отмечаются.
9. `/goals` создаёт измеримые цели на 90 календарных дней, хранит недельное
   действие и обновляет прогресс. Тег цели связывает задачи с целью.

### Напоминания и запуск

10. Утро, вечер, недельный обзор и приближение события вычисляются в часовом
    поясе таблицы. Настройки и тихие часы доступны через `/reminders`.
    Идемпотентность сохраняется между запусками, просроченные события не шлются.
11. На Windows long polling и последовательный планировщик работают в одном
    процессе. При сне/выключении компьютера сообщения не доставляются;
    пропущенные напоминания не отправляются пачкой после запуска.
    В webhook-режиме нужен внешний вызов cron каждую минуту.

### Коучинг и проверка

12. `/coaching` показывает состав сводки. Экспорт — после согласия, по отдельной
    команде, только владельцу. В файле агрегаты за 7 дней без названий задач,
    дневниковых текстов, идентификаторов и секретов. `/coaching off` отзывает
    согласие. Сетевой передачи в ChatGPT и публичного API на этом этапе нет.
    Пользователь сам решает, загрузить ли файл в чат; отозвать уже выданный
    файл технически невозможно. Это рабочий первый канал обмена, дальнейший
    автоматический доступ потребует отдельно согласованного развёртывания.
13. Проверить: старый Markdown, стабильные ID, реальную дату завершения,
    лимит приоритетов, смену режимов, DST/полночь, тихие часы, повторы cron,
    конфликты записи, приватность хранилища, чужие/групповые запросы,
    согласие/отзыв/состав экспорта. Запустить всю тестовую базу, типизацию и lint.

## Готовность

Код и инструкции для Windows доступны для проверки, автоматические проверки
проходят. Живой запуск требует локальных секретов владельца; секреты не
запрашиваются в чате, существующий работающий экземпляр здесь не запускается.
