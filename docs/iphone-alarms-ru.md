# Будильники iPhone через «Команды»

Связка рассчитана на три фиксированных будильника: **08:00, 08:05, 08:10**.
Бот копирует короткий план в буфер обмена. Ты запускаешь локальную команду
на iPhone, и она включает или выключает три выбранных будильника.
Бот не получает удалённого доступа к iPhone и не проверяет выполнение.
Telegram-уведомления зависят от работающего компьютера;
будильники в «Часах» после включения работают на самом телефоне.

## Настройка один раз

1. В **Часы → Будильники** создай:
   - `TaskManager Wake 08:00` — 08:00;
   - `TaskManager Wake 08:05` — 08:05;
   - `TaskManager Wake 08:10` — 08:10.

   Для ежедневного подъёма выбери повтор во все дни недели. Выбери звук
   и проверь громкость. Если нужны разовые сигналы, оставь «Повтор → Никогда»;
   после срабатывания их потребуется снова включать.

2. Открой **Команды**, создай новую команду **TaskManager Alarms**.
3. Добавь действие **Получить буфер обмена / Get Clipboard**.
4. Добавь **Если / If**. Сравни результат предыдущего действия с точным текстом:

   ```text
   TMALARM1
   on
   08:00
   08:05
   08:10
   ```

   Условие — **совпадает / is**, с настоящими переносами строк, без пробелов
   по краям. Не используй условие «содержит».

5. Внутри этой ветки добавь три действия **Toggle Alarm** из приложения
   «Часы». Для каждого выбери **Turn → On** (включить), затем явно выбери
   один из трёх созданных будильников. В разных языках iOS название действия
   может выглядеть как «Включить/выключить будильник».
6. В **Иначе / Otherwise** добавь второй **Если**, сравнивая тот же результат
   «Получить буфер обмена» с точным текстом:

   ```text
   TMALARM1
   off
   08:00
   08:05
   08:10
   ```

7. Во второй ветке добавь три **Toggle Alarm → Turn → Off** (выключить),
   явно выбрав те же три будильника. Выбирай **Turn**, а не переключение
   текущего состояния: повторный запуск должен оставлять нужное состояние.
8. Во внутреннем **Иначе** добавь **Показать результат / Show Result**:
   «Будильники не изменены: скопируй план TaskManager», затем
   **Остановить эту команду / Stop This Shortcut**. Закрой оба «Если».

Команда только меняет состояние выбранных будильников. Создавать и удалять
будильники, передавать токены или обращаться к серверу ей не требуется.
На первом запуске разреши доступ к буферу обмена и «Часам», если iOS запросит.

## Применение

1. В боте: **Мой день → Мой режим → Будильники iPhone**.
   Настройки разбиты на страницы; используй стрелку вправо.
2. Нажми **Скопировать включение** или **Скопировать выключение**.
3. На iPhone вручную запусти **TaskManager Alarms** в «Командах».
4. При первой проверке открой «Часы»: измениться должны только эти три
   будильника. Проверь включение и выключение; затем снова включи их.

Команду можно вынести на домашний экран. Автоматического запуска из Telegram
сейчас нет. «Я встал» останавливает только Telegram-повторы; будильники iPhone
выключаются на телефоне или через описанную команду.

При смене времени подъёма отдельно измени время этих трёх будильников
в «Часах». Оба условия «Если» оставь в точности как выше: строки
08:00/08:05/08:10 — постоянные метки протокола, а не новое расписание.
Кнопки меняют только состояние выбранных будильников; они не задают время.
Бот предупреждает, если его подъём отличается от исходного шаблона 08:00,
и не может проверить фактические настройки телефона.
Готового проверенного установочного файла `.shortcut` в этой версии нет:
команда создаётся на твоём iPhone.

Apple описывает [создание команд](https://support.apple.com/guide/shortcuts/create-a-custom-shortcut-apd84c576f8c/ios)
и действия Create Alarm, Toggle Alarm и Get All Alarms в
[обновлениях «Команд»](https://support.apple.com/en-sg/101583).
Отдельное приложение с [AlarmKit](https://developer.apple.com/documentation/AlarmKit/scheduling-an-alarm-with-alarmkit)
потребует установки и системного разрешения; в этом проекте такого приложения нет.
